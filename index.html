funground-web

funground in the browser: a learner's Python sketch runs in a web page, with no installing.

funground is a small Python library for learning to code by drawing. This repository is its web target. It runs Python (Pyodide) in a Web Worker, and draws with funground's own renderer: Cairo, HarfBuzz and Skia's path tools, compiled to WebAssembly. Nothing is stubbed, so a sketch draws the same picture in the browser as on a computer. Sound and the microphone go through Web Audio, the camera through the browser, and pose and hand tracking through onnxruntime-web.

What is here

FolderWhat it holds
runner/The browser runner: runner.js (the page side), worker.js (Python in a module worker), sound, microphone, camera and models. How a page uses it
vscode-extension/A VS Code extension that runs a sketch in a panel beside the editor, on the desktop and in github.dev
tools/Builds the runtime (build_runtime.py) and tests the runner in headless Chrome

Quick usage guide

  1. Build the runtime. The runner needs runner/runtime/: funground's wheel, the compiled libraries and a manifest. It is built, not stored in the repository, so it is not on this site. From a checkout of this repository and of funground: 
    python tools/build_runtime.py --funground path/to/funground
  2. Serve the folder from any static web server. Pyodide itself comes from jsDelivr.
  3. Make a runner and run a sketch from a page: 
    <canvas id="canvas" width="640" height="400"></canvas>
<pre id="output"></pre>
<script type="module">
  import { createRunner } from "./runner/runner.js";

  const runner = await createRunner({
    canvas: document.getElementById("canvas"),
    output: document.getElementById("output"),   // print() and tracebacks
  });                                             // resolves when Python is ready

  const source = `import funground as f

def draw():
    f.background("white")
    f.circle(f.mouse_x, f.mouse_y, 40)

f.run()`;
  await runner.run(source, { filename: "sketch.py" });
  // runner.stop() ends the run at once, even a `while True:` loop
</script>
  4. Go further: files beside the sketch, saved files, sound, the camera, models and the options for editors are in the runner's README. runner/demo.html is a working example page.

Try it without building

The phone check loads Pyodide alone (no funground), and runs a short plain Python script, then shows how long it took. It works on a phone too.
